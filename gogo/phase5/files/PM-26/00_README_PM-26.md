- **Phase**: `Phase 5: Commissioning L1-L5 & Integrated Testing (RIBA 5-6)`
- **RIBA Stage**: `RIBA Stage 4-5`

- **WBS Scope**: `WBS 6.1-L12`

Execute European Factory Acceptance Tests (HV switchgear, UPS, chillers, BESS) and verify undamaged site installation/red-line tags.

## Study Takeaway (`Why Each Document Matters`)
- **Doc 1 (Standard)**: Understand rated impulse withstand, UPS overload specs, and ISO G3 genset classes.
- **Doc 2 (Deliverable)**: Catch protection/firmware defects in the factory before shipping to Dublin/Cork.
- **Doc 3 (Template)**: Verify shock-recorder logs, anchor bolts, and megger tests prior to Yellow Tag sign-off.
- **Doc 4 (Audit)**: Control physical lockstep gates so no contractor energizes an unverified panel.
