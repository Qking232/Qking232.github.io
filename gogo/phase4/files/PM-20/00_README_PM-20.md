# PM-20: Integrated Change Control (CRB), Scope Freeze & Baselines

- **Phase**: `Phase 4: Execution, Controls, Risk & Change (RIBA 5)`
- **RIBA Stage**: `RIBA Stage 4-6`
- **P6 Milestone Gate**: `Baseline Governance`
- **WBS Scope**: `All WBS`
- **Governing Standards**: ISO 10007 Configuration Management, SteerCo DoA Tiers 0-3
- **Focus Areas**: CRB / SteerCo, Change Impact Form, BAC / Float Lock, Scope Freeze Waivers, Baseline Revisions

## Module Overview
Govern Change Requests through technical/cost/schedule impact scoring before Change Control Board sign-off and baseline revision.

## Study Takeaway (`Why Each Document Matters`)
- **Doc 1 (Standard)**: Enforce strict separation between pending tenant wishes and approved baseline changes.
- **Doc 2 (Deliverable)**: Clarify PM vs. Sponsor approval caps so minor field tweaks move without stalling.
- **Doc 3 (Template)**: Force holistic impact sign-off on load density, P6 float, and PUE before issuing VOs.
- **Doc 4 (Audit)**: Trace every EUR moved from contingency and justify late tenant variation orders.
