## Study Takeaway (`Why Each Document Matters`)
- **Doc 1 (Standard)**: Learn mandatory physical security setbacks, flood immunity, and external hazard rules.
- **Doc 2 (Deliverable)**: Synthesize grid substation distance, dual-path dark fibre, and zoning viability for FID.
- **Doc 3 (Template)**: Quantify site trade-offs objectively across capex penalties and schedule risk.
- **Doc 4 (Audit)**: Eliminate fatal subsurface, contamination, UXO, or fluvial flood blockers before closing.
